# 🎯 Guess My Number Game

A fun number-guessing game built using **HTML, CSS, and JavaScript**, following the _Complete JavaScript Course_ by Jonas Schmedtmann on Udemy.

## 📌 About the Project

Guess My Number is a simple interactive game in which the player tries to guess a secret number between 1 and 20. After each guess, the game provides feedback to help the player determine whether the guess is too high or too low.

The goal is to guess the correct number while maintaining the highest possible score.

## 🚀 Features

- Random secret number generation.
- Interactive number guessing.
- Feedback for guesses that are too high or too low.
- Score reduction for incorrect guesses.
- High score tracking.
- Restart the game using the **Again!** button.
- Responsive and visually engaging user interface.

## 🛠️ Technologies Used

- **HTML5** — Page structure.
- **CSS3** — Styling and layout.
- **JavaScript (ES6+)** — Game logic and interactivity.

## 🧠 Concepts Practised

- DOM manipulation.
- Event listeners and event handling.
- Conditional statements (`if/else`).
- Functions and variables.
- Random number generation using `Math.random()`.
- Updating HTML elements dynamically.
- Managing game state and scores.

## 🎮 How to Play

1. Start the game and enter a number between **1 and 20**.
2. Click **Check!** to submit your guess.
3. Read the feedback:
   - **Too high!** — Try a smaller number.
   - **Too low!** — Try a larger number.
   - **Correct number!** — You win!
4. Try to guess the secret number before your score reaches zero.
5. Click **Again!** to start a new round.

## 💻 How to Run Locally

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
4. Start guessing!

Replace `YOUR_REPOSITORY_URL` with your actual GitHub repository URL.
